# 生成AI 50のチャレンジⅢ ～授業改善で使える生成AI～

**公開ページ: https://kumaken-1.github.io/lesson-improvement-ai-50/**

教材研究、子どもの現在地、問い、活動と対話、見取り、授業後の見直し。
この6つの場面について、生成AIと2往復するだけの短い回を50並べたものです。
1回10分ほど。順番どおりでなくても、1回だけでもかまいません。

## 進め方

あなたが送るのは2回です。

1. **1回目に送る** — その回の相談文を送ります。
2. **AIの回答を読む** — 読む前に、自分ならどう答えるかを一つ決めてから読みます。
3. **2回目に送る** — 全50回で共通の文の空欄をうめて、同じ会話の続きとして送ります。

読んだら、採用するか、直すか、使わないかを決めます。**使わないという判断も、その回の結論です。**

最後に、次の授業で変える一点を一行だけ書き留めます。書く場所はこの画面ではなく、手元の手帳や指導案です。

## 送る文に付く制約

全50回とも、Web検索をせず、渡した情報だけを使い、各項目を2文以内にする、という制約が付いています。
長く整った回答や、検索してきた権威ある記述は、教師の判断を弱めます。
必要なのは、短時間で吟味できる分量の回答です。

学習指導要領の記述や教科の理論をAIに尋ねる回はありません。AIは平然と存在しない記述を作ります。
事実は原典で確かめてください。AIに渡すのは、自分が持っている教材、授業案、授業記録、自分の考えだけです。

## 個人情報について

児童生徒の実名、成績、健康、家庭のことは入力しません。名前は「児童A」などに置き換えます。
この画面は、入力した言葉を一切保存しません。端末に残るのは「やってみた」の回番号だけです。
